# Input

Use inside Field for label/hint/error wiring; outside Field provide an accessible
name. Props include native input props, size (sm, md, lg, portal, portal-sm),
surface (page or paper), invalid and className. Ref points to the input.
Shared staff controls are 16px on coarse pointers, 13px on fine pointers; portal
sizes remain 16px. Keep the shared border, focus and disabled recipe.
