# Completed implementation plans

This directory is the durable completion record for plans created under the
current planning standard.

No current-standard plans had completed at the point this directory was
introduced on 9 August 2026. Earlier completed plans remain in
[`../../archive/superpowers/plans/`](../../archive/superpowers/plans/) so their
links and history are preserved.

When a plan completes:

1. verify its definition of done and record the evidence;
2. move the file from `../active/` without rewriting its original decisions;
3. link the closing pull request and release evidence; and
4. update the issue and changelog.
